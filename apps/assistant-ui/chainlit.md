# 公司 M 內部助理（示範）

公司 M 是虛構的公司，賣肺結節 AI 輔助偵測軟體，軟體裝在醫院的地端 GPU 推論主機上。這個介面是公司**內部**人員用的助理：品保、服務、研發、法規與主管。

## 可以做什麼

- **查 ERP／QMS**：站點、CT 機型、推論主機版本、零件批號追溯、客訴、CAPA。只用固定格式的查詢，資料庫唯讀。
- **查知識庫**：SOP、規格書、FDA 指引與 510(k) 摘要。依你的身分過濾，看不到沒有權限的文件。
- **查公開資料**：openFDA 的 510(k) 與召回紀錄。
- **起草**：CAPA、服務工單、客戶通知。只會產生草稿，要由品保主管在「待核准」核准後才生效，每個決定都會寫入稽核紀錄。

## 怎麼試

1. 左上角選身分。換身分就是換一個人登入。
2. 點範例問題，或直接輸入問題。
3. 每次工具呼叫都會列出來，展開可以看到參數和回傳內容。
4. 以品保工程師身分起草 CAPA，再切換成品保主管，輸入「待核准」核准；輸入「稽核紀錄」查看紀錄。

## 注意

- 全部是合成資料與公開資料，名稱都是中性代稱（醫院A、CT 廠牌A）。研究與學習用途，**非醫療器材，不做臨床判斷**。
- 沒有設定模型時，回答來自「固定流程」：依規則判斷問題，再呼叫工具，不會自己推理。設定 `ASSISTANT_LLM_BASE_URL` 與 `ASSISTANT_LLM_MODEL` 之後，改由模型決定要呼叫哪些工具。
