# NoduleAssist 1.2 產品規格書（PS-NA1，版次 1.2）

> 虛構產品，所有規格與性能數值都是合成的，不代表任何真實產品。

## 1. 預期用途
NoduleAssist 是電腦輔助偵測（CADe）軟體，在成人胸腔 CT 上標示可能的實質性肺結節，供放射科醫師判讀時參考。最終判讀由醫師負責；軟體不提供診斷，也不判斷結節良惡性。

## 2. 輸入規格

| 項目 | 規格 |
|---|---|
| 影像類型 | 胸腔 CT，DICOM |
| 切片厚度 | ≤ 2.5 mm |
| 切片數 | ≥ 60 |
| 切片間距 | 必須等距 |
| 管電壓 | 100–140 kVp |
| 病人 | 成人（18 歲以上） |

不符合輸入規格的序列由系統拒收，並在結果中說明拒收原因（1.2 版起）。

## 3. 已驗證 CT 機型
NoduleAssist 1.2 已在下列機型完成驗證：CT廠牌A A-64、A-128；CT廠牌B B-80、B-256；CT廠牌C C-64。

不在清單內的機型（例如 CT廠牌C C-320）尚未驗證。站點若要接上未驗證機型，依 QMS-SOP-012 第 3 節處理。

## 4. 性能
在 300 例獨立測試集（3 家醫院、5 種 CT 機型）上：

| 指標 | 結果 |
|---|---|
| 每例誤報 1 個時的敏感度 | 0.88 |
| 每例誤報 2 個時的敏感度 | 0.92 |
| 3–6 mm 結節敏感度（1 FP/scan） | 0.79 |
| 單例處理時間中位數（NA-100） | 95 秒 |

## 5. 部署環境
軟體只在公司 M 提供的推論主機（NA-100、NA-200）上執行，影像不離開醫院網路。主機規格見 HW-NA。
